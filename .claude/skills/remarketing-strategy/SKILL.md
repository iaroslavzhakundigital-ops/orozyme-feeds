## Best Practices

1. Segment remarketing lists by funnel stage — never target all visitors with the same message
2. Use shorter membership durations (7-14 days) for bottom-funnel audiences
3. Implement frequency capping to prevent ad fatigue (3-5 impressions/day)
4. Build sequential messaging chains that move users toward conversion
5. Use dynamic remarketing for e-commerce to show specific products viewed
