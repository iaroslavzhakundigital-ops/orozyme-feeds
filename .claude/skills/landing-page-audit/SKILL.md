# Landing Page Audit

Part of [Agent Skills™](https://github.com/itallstartedwithaidea/agent-skills) by [googleadsagent.ai™](https://googleadsagent.ai)

## Description

Performs comprehensive evaluations of post-click experiences combining Core Web Vitals analysis with CRO assessment. Audits speed (LCP, INP, CLS), relevance (message match, keyword coverage), and persuasion (CTA, form design, trust signals).

## Use When

- User asks for a "landing page audit" or "page review"
- User mentions "landing page experience" Quality Score component
- User wants to "improve conversion rate" or "CRO analysis"
- User asks about "page speed" or "Core Web Vitals"
- User mentions "low conversion rate" on specific pages
- User wants "form optimization" or "CTA optimization" advice

## Best Practices

1. Target LCP under 2.5 seconds on mobile
2. Ensure primary CTA is visible above the fold on both mobile and desktop
3. Match the exact language from top-performing ad headlines on the landing page
4. Limit form fields to the minimum necessary
5. Include at least three trust signals: reviews, security badges, certifications
