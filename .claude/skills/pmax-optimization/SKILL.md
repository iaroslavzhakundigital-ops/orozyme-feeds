# Performance Max Optimization

Part of [Agent Skills™](https://github.com/itallstartedwithaidea/agent-skills) by [googleadsagent.ai™](https://googleadsagent.ai)

## Description

Provides expert-level management of Performance Max (PMax) campaigns across all Google inventory. Addresses asset group architecture, audience signals, URL strategies, search themes, and negative controls.

## Use When

- User asks about "Performance Max" or "PMax" campaigns
- User wants to "optimize PMax" or "improve PMax performance"
- User mentions "asset groups" or "asset performance"
- User asks about "audience signals" for PMax
- User mentions "PMax cannibalization" of Search campaigns

## Best Practices

1. Create separate asset groups for distinct product categories or audience segments
2. Provide at least 15 headlines, 4 descriptions, 15 images, and 1+ custom videos per asset group
3. Upload custom videos to prevent Google auto-generating low-quality videos
4. Add search themes to guide PMax's Search inventory placement
5. Allow 4-6 weeks for PMax to exit the learning phase before structural changes
